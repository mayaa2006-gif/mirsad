اللغات والتقنيات المستخدمة

HTML5 وCSS3

بناء صفحات الموقع بواجهة عربية من اليمين إلى اليسار، وتصميم يتكيّف مع الجوال والحاسب.

JavaScript

منطق الأداة داخل المتصفح: قراءة بيانات EXIF المخفية، وتغطية العناصر الحساسة بالرسم على Canvas، وحساب درجة الأمان.

Python وPillow

أدوات مساعدة خارج الموقع: توليد 30 صورة تجريبية ببيانات وهمية وملف الإجابات الصحيحة، وحساب الدقة.

Gemini API

نموذج رؤية حاسوبية يقرأ النصوص ويفهم سياق الصورة، وتخرج نتيجته بالعربي مع تحديد أماكن التسريب.

GitHub Pages

استضافة الموقع ونشره برابط عام، وإدارة نسخ الملفات على GitHub.

Cloudflare Workers

وسيط صغير يحفظ مفتاح Gemini على الخادم بعيدًا عن الواجهة، فيعمل الذكاء الاصطناعي لكل الزوار دون مفتاح.
